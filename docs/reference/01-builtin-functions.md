# الدوال المدمجة

مرجع شامل لجميع الدوال المدمجة في لغة كنوز.

## دوال الطباعة

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `اطبع(نص)` | طباعة نص | `اطبع("مرحباً")` |
| `اطبع_سطر!(نص)` | طباعة مع سطر جديد | `اطبع_سطر!("مرحباً")` |
| `اطبع_صحيح(ص)` | طباعة عدد صحيح | `اطبع_صحيح(42)` |
| `اطبع_عشري(ع)` | طباعة عدد عشري | `اطبع_عشري(3.14)` |
| `اطبع_منطقي(م)` | طباعة قيمة منطقية | `اطبع_منطقي(صح)` |
| `طباعة(تنسيق, ...)` | طباعة منسقة | `طباعة("{}", قيمة)` |

### أمثلة الطباعة

```knoz
اطبع("رسالة بسيطة");
اطبع_صحيح(42);
اطبع_عشري(3.14159);
اطبع_منطقي(صح);

// طباعة منسقة مع القيم داخل النص
دع اسم = "أحمد";
دع عمر = 25;
اطبع_سطر!("الاسم: {اسم} العمر: {عمر}");

// طباعة منسقة بأسلوب printf
اطبع_سطر!("الرقم: {}", 42);
```

## دوال الرياضيات

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `جذر_تربيعي(ع)` | الجذر التربيعي | `جذر_تربيعي(16.0)` → `4.0` |
| `قوة_ع(قاعدة, أس)` | الأُس | `قوة_ع(2.0, 10.0)` → `1024.0` |
| `مطلق_عشري(ع)` | القيمة المطلقة | `مطلق_عشري(-15.7)` → `15.7` |
| `جيب(زاوية)` | جيب الزاوية | `جيب(0.0)` → `0.0` |
| `جتا(زاوية)` | جيب تمام الزاوية | `جتا(0.0)` → `1.0` |
| `عشوائي()` | رقم عشوائي | `عشوائي()` |

### أمثلة الرياضيات

```knoz
// الجذر التربيعي
دع جذر = جذر_تربيعي(144.0);  // 12.0

// الأُس
دع قوة = قوة_ع(2.0, 10.0);  // 1024.0

// القيمة المطلقة
دع مطلق = مطلق_عشري(-42.0);  // 42.0

// المثلثات
دع جيب_صفر = جيب(0.0);  // 0.0
دع جتا_صفر = جتا(0.0);  // 1.0
```

## دوال التقريب

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `تقريب(ع)` | التقريب لأقرب صحيح | `تقريب(3.7)` → `4` |
| `أرضية(ع)` | التقريب للأسفل | `أرضية(3.7)` → `3` |
| `سقف(ع)` | التقريب للأعلى | `سقف(3.2)` → `4` |

```knoz
دع ع = 3.7;
اطبع_صحيح(تقريب(ع));   // 4
اطبع_صحيح(أرضية(ع));  // 3
اطبع_صحيح(سقف(ع));    // 4
```

## دوال التحويل

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `صحيح_لنص(ص)` | تحويل صحيح لنص | `صحيح_لنص(123)` → `"123"` |
| `صحيح_لعشري(ص)` | تحويل صحيح لعشري | `صحيح_لعشري(100)` → `100.0` |
| `عشري_لصحيح(ع)` | تحويل عشري لصحيح | `عشري_لصحيح(3.9)` → `3` |
| `منطقي_لنص(م)` | تحويل منطقي لنص | `منطقي_لنص(صح)` → `"صح"` |

```knoz
// صحيح إلى نص
دع كنص = صحيح_لنص(123);
اطبع(كنص);

// صحيح إلى عشري
دع كعشري = صحيح_لعشري(100);
اطبع_عشري(كعشري);

// عشري إلى صحيح
دع كصحيح = عشري_لصحيح(3.9);
اطبع_صحيح(كصحيح);  // 3

// منطقي إلى نص
دع نص_منطقي = منطقي_لنص(صح);
اطبع(نص_منطقي);
```

## دوال النصوص

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `طول(نص)` | طول النص | `طول("مرحبا")` → `5` |

```knoz
دع الطول = طول("مرحبا عالم");
اطبع_صحيح(الطول);
```

## دوال الوقت

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `وقت()` | الوقت الحالي (ثواني منذ 1970) | `وقت()` |

```knoz
دع الوقت_الحالي = وقت();
اطبع_صحيح(الوقت_الحالي);
```

## دوال الذاكرة

| الدالة | الوصف | مثال |
|--------|--------|-------|
| `احجز(حجم)` | حجز ذاكرة | `احجز(100)` |
| `حرر(مؤشر)` | تحرير ذاكرة | `حرر(ذاكرة)` |

```knoz
دع ذاكرة = احجز(100);
إذا ذاكرة != 0 {
    // استخدم الذاكرة
    حرر(ذاكرة);
}
```

## دوال الملفات

| الدالة | الوصف |
|--------|--------|
| `افتح_ملف(مسار, وضع)` | فتح ملف ("w", "r", "a") |
| `أغلق_ملف(ملف)` | إغلاق ملف |
| `اكتب_نص_ملف(نص, ملف)` | كتابة في ملف |
| `احذف_ملف(مسار)` | حذف ملف |
| `موقع_ملف(ملف)` | موقع المؤشر في الملف |

```knoz
دع ملف = افتح_ملف("/tmp/test.txt", "w");
اكتب_نص_ملف("محتوى\n", ملف);
أغلق_ملف(ملف);
احذف_ملف("/tmp/test.txt");
```

## المثال الكامل

```knoz
دالة رئيسية() {
    اطبع("=== الدوال المدمجة ===");
    
    // الطباعة
    اطبع("رسالة");
    اطبع_صحيح(42);
    اطبع_عشري(3.14);
    
    // الرياضيات
    اطبع("=== الرياضيات ===");
    اطبع_عشري(جذر_تربيعي(144.0));
    اطبع_عشري(قوة_ع(2.0, 10.0));
    اطبع_عشري(مطلق_عشري(-42.0));
    
    // التقريب
    اطبع("=== التقريب ===");
    اطبع_صحيح(تقريب(3.7));
    اطبع_صحيح(أرضية(3.7));
    اطبع_صحيح(سقف(3.2));
    
    // التحويل
    اطبع("=== التحويل ===");
    دع كنص = صحيح_لنص(123);
    اطبع(كنص);
    
    // الوقت
    اطبع("=== الوقت ===");
    اطبع_صحيح(وقت());
    
    // طول النص
    اطبع("=== طول النص ===");
    اطبع_صحيح(طول("مرحبا عالم"));
}
```
