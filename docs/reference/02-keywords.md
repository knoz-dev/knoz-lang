# الكلمات المحجوزة

قائمة شاملة بجميع الكلمات المحجوزة في لغة كنوز.

## التعريفات

| الكلمة | المقابل الإنجليزي | الوصف |
|--------|------------------|--------|
| `دع` | let | تعريف متغير |
| `متغير` | mut | تحديد المتغير كقابل للتغيير |
| `ثابت` | const | قيمة ثابتة |
| `دالة` | fn | تعريف دالة |
| `هيكل` | struct | تعريف هيكل |
| `تعداد` | enum | تعريف تعداد |
| `سمة` | trait | تعريف سمة |
| `نفذ` | impl | تنفيذ سمة |
| `لـ` | for | للاستخدام مع نفذ |

## أمثلة الاستخدام

```knoz
// التعريفات
دع عدد = 42;
دع متغير عداد = 0;

// الدالة
دالة مربع(س: صحيح) -> صحيح {
    أرجع س * س;
}

// الهيكل
هيكل نقطة {
    س: صحيح,
    ص: صحيح
}

// التعداد
تعداد لون {
    أحمر,
    أخضر
}

// التحكم
إذا عدد > 0 {
    اطبع("موجب");
} وإلا {
    اطبع("سالب أو صفر");
}

// الحلقة
لكل ي في 1..5 {
    اطبع_صحيح(ي);
}

// المطابقة
طابق عدد {
    0 => { اطبع("صفر"); }
    _ => { اطبع("غير صفر"); }
}

// معالجة الأخطاء
جرب {
    ألق "خطأ"
} التقط خ {
    اطبع("تم التقاط الخطأ");
} أخيرا {
    اطبع("تنظيف");
}

// النتيجة
دالة قسمة(أ: صحيح, ب: صحيح) -> نتيجة<صحيح, نص> {
    إذا ب == 0 {
        أرجع فشل("قسمة على صفر");
    }
    أرجع موافق(أ / ب);
}
```
