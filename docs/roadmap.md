##  خارطة الطريق

تحدد هذه الوثيقة التطور المخطط للغة البرمجة **كنوز**، ومترجمها، وأدواتها، ونظامها البيئي.

تُعطي خارطة الطريق الأولوية لـ **الاستقرار والصحة ونضج النظام البيئي** على التوسع السريع في الميزات.

---

## الحالة الراهنة

**الإصدار:** `1.0.0-beta`  
**المرحلة:** النسخة التجريبية العامة  
**التركيز:** الاستقرار، التوثيق، تأسيس النظام البيئي

كنوز هي لغة حديثة مبنية على LLVM وتتميز بـ:
- دلالات ثابتة قوية (Strong static semantics)
- دعم الماكروات الإجرائية
- مدير حزم مدمج
- أدوات توثيق وتغطية مدمجة
- هوية عربية

---

## المرحلة الأولى — استقرار النسخة التجريبية

**الهدف:** جعل كنوز آمنة وموثوقة للمستخدمين الأوائل.

### اللغة والمترجم
- تجميد صيغة اللغة
- ضمان التوافق مع الإصدارات السابقة خلال النسخة التجريبية
- تحسين تشخيص الأخطاء ودقة تحديد المواقع
- توحيد صيغة الأخطاء والتقارير

### بيئة التشغيل
- تثبيت واجهة ABI لبيئة التشغيل
- تثبيت واجهة المخصص (allocator)
- إنهاء واجهات برمجة الخيوط والمزامنة
- توثيق الرموز العامة مقابل الداخلية

### الأدوات
- تقوية أوامر CLI (`بناء`، `شغل`، `اختبار`، `وثق`)
- تحسين موثوقية الترجمة التزايدية
- تثبيت سلوك تحميل الماكروات الإجرائية

### التكامل المستمر والتوزيع
- بناءات GitHub Actions (لينكس، ماك، ويندوز)
- ملفات إصدار موقعة
- خيار بيئة تشغيل ثابتة حيثما أمكن

**المعلم:** `1.0.0-beta.2`

---

## المرحلة الثانية — الإصدار المستقر والتبني

**الهدف:** تمكين المشاريع الحقيقية بثقة.

### تجربة المطور
- تحسينات المنسق (Formatter)
- استقرار وأداء LSP
- بناءات تزايدية أسرع

### مدير الحزم
- إنهاء صيغة ملف القفل (lockfile)
- حل الاعتماديات بشكل حتمي
- دعم التخزين المؤقت للعمل بدون اتصال

### الاختبار والجودة
- تنفيذ الاختبارات بشكل متوازي
- تصفية وتجميع الاختبارات
- عتبات التغطية (`--fail-under`)

### التوثيق
- أدلة عملية:
  - أدوات سطر الأوامر
  - أدوات نظام الملفات
  - خدمات HTTP

**المعلم:** `1.0.0 (مستقر)`

---

## المرحلة الثالثة — القدرات المتقدمة

**الهدف:** المنافسة الجادة مع لغات الأنظمة الحديثة.

### الماكروات الإجرائية v2
- نموذج صحة اختياري (hygiene)
- واجهة ABI مستقرة للماكروات
- استكشاف ماكروات WASM المعزولة

### التحليل الدلالي v2
- فحص الشمولية الحقيقي (exhaustiveness)
- تحليل تدفق البيانات
- تحليل الهروب (أساس للتحسينات المستقبلية)

### أدوات الأداء
- خطافات تحليل الأداء المدمجة
- إخراج Flamegraph
- دعم تحليل الذاكرة

### FFI والتوافقية
- مولد C ABI
- توليد الترويسات تلقائياً
- تكامل أسهل مع مكتبات C الموجودة

**المعلم:** `1.1 / 1.2`

## المرحلة الرابعة — التوسع الاستراتيجي

**الهدف:** اختيار اتجاه هوية طويل المدى بناءً على نمو المجتمع.

### المسارات المحتملة (اتجاه رئيسي واحد)

#### أ. التركيز على برمجة الأنظمة
- وضع بدون بيئة تشغيل
- مجموعة فرعية صديقة للمضمنات والنواة
- التركيز على التحكم المنخفض المستوى

#### ب. التركيز على الأدوات والخوادم
- بيئة تشغيل غير متزامنة (async)
- مكتبات قياسية لـ HTTP و JSON وقواعد البيانات
- نموذج نشر بسيط

#### ج. منصة لغوية
- مترجم ذاتي الاستضافة (كنوز تترجم كنوز)
- نظام حزم بيئي ناضج
- أدوات مطور مبنية بكنوز

## الفلسفة

تُعطي كنوز الأولوية لـ:
- أخطاء وقت الترجمة بدل مفاجآت وقت التشغيل
- سلوك حتمي عبر جميع الأنظمة
- كود مقروء أهم من كود مختصر
- الاستقرار طويل المدى على الضجة قصيرة المدى
