## 📚 Documentation

مرحباً بك في لغة كنوز البرمجية! كنوز هي لغة برمجة عربية حديثة مصممة لجعل البرمجة أكثر وضوحاً وسهولة للمتحدثين بالعربية. تتميز كنوز بنظام أنواع قوي، معالجة أخطاء متقدمة، ودعم كامل للبرمجة المتزامنة.

هذا الدليل سيأخذك خطوة بخطوة من التثبيت إلى كتابة أول برنامج لك. في نهاية هذا الدليل، ستكون قادراً على:
- تثبيت كنوز على جهازك
- إنشاء وتشغيل برامج كنوز
- فهم البنية الأساسية للمشاريع
- البدء في تعلم ميزات اللغة

## تثبيت كنوز

### التثبيت السريع (موصى به)

أسرع وأسهل طريقة لتثبيت كنوز على Linux أو macOS:

```bash
curl -fsSL https://sh.knoz.dev | sh
```

هذا الأمر سيقوم تلقائياً بـ:
- تحديد نظام التشغيل والمعمارية
- تحميل النسخة المناسبة
- تثبيت كنوز في المسار الصحيح
- إضافة كنوز إلى PATH

### Windows

لمستخدمي Windows، حمّل المثبت من صفحة التحميل:

**[تحميل كنوز لـ Windows ←](/guides/download/)**

### التحقق من التثبيت

```bash
# عرض النسخة
knoz --نسخة

# عرض المساعدة
knoz --مساعدة
```

يجب أن ترى:
```
كنوز - لغة البرمجة العربية
الإصدار: 1.0.0
```

**للمزيد من خيارات التثبيت:** [صفحة التحميل ←](/guides/download/)

## أول برنامج لك

### 1. إنشاء مشروع جديد

```bash
# إنشاء مشروع جديد
knoz جديد مرحبا
cd مرحبا
```

هذا ينشئ الهيكل التالي:

```
مرحبا/
├── كنوز.toml
└── مصدر/
    └── رئيسي.كنز
```

### 2. محتوى الملف

افتح `مصدر/رئيسي.كنز` وستجد:

```knoz
دالة رئيسية() {
    طباعة("مرحباً بالعالم!")؛
}
```

### 3. تشغيل البرنامج

```bash
# طريقة 1: تشغيل مباشر
knoz شغّل

# طريقة 2: بناء ثم تشغيل
knoz ابنِ
./مرحبا  # Linux/macOS
مرحبا.exe  # Windows
```

النتيجة:
```
مرحباً بالعالم!
```

## مثال: حاسبة بسيطة

لنكتب برنامجاً أكثر تفاعلية!

### 1. إنشاء المشروع

```bash
knoz جديد حاسبة
cd حاسبة
```

### 2. كتابة الكود

عدّل `مصدر/رئيسي.كنز`:

```knoz
دالة رئيسية() {
    طباعة("=== حاسبة بسيطة ===")؛
    طباعة()؛
    
    // إدخال الأرقام
    دع أ = 10؛
    دع ب = 5؛
    
    // العمليات الحسابية
    دع جمع = أ + ب؛
    دع طرح = أ - ب؛
    دع ضرب = أ * ب؛
    دع قسمة = أ / ب؛
    
    // عرض النتائج
    طباعة("{} + {} = {}", أ, ب, جمع)؛
    طباعة("{} - {} = {}", أ, ب, طرح)؛
    طباعة("{} × {} = {}", أ, ب, ضرب)؛
    طباعة("{} ÷ {} = {}", أ, ب, قسمة)؛
}
```

### 3. التشغيل

```bash
knoz شغّل
```

النتيجة:
```
=== حاسبة بسيطة ===

10 + 5 = 15
10 - 5 = 5
10 × 5 = 50
10 ÷ 5 = 2
```

## مثال: دالة مع معالجة الأخطاء

```knoz
دالة قسمة(أ: صحيح, ب: صحيح) -> نتيجة<صحيح, نص> {
    إذا ب == 0 {
        فشل("لا يمكن القسمة على صفر")
    } وإلا {
        موافق(أ / ب)
    }
}

دالة رئيسية() {
    طباعة("=== معالجة الأخطاء ===")؛
    طباعة()؛
    
    // حالة ناجحة
    طابق قسمة(10, 2) {
        موافق(نتيجة) => طباعة("✓ 10 ÷ 2 = {}", نتيجة),
        فشل(خطأ) => طباعة("✗ خطأ: {}", خطأ),
    }
    
    // حالة خطأ
    طابق قسمة(10, 0) {
        موافق(نتيجة) => طباعة("✓ 10 ÷ 0 = {}", نتيجة),
        فشل(خطأ) => طباعة("✗ خطأ: {}", خطأ),
    }
}
```

رخصة = "MIT"

## أمثلة إضافية

### حلقة تكرارية

```knoz
دالة رئيسية() {
    // طالما (while)
    دع متغير عداد = 0؛
    طالما عداد < 5 {
        طباعة("العداد: {}", عداد)؛
        عداد += 1؛
    }
    
    // لكل (for)
    لكل رقم في 1..=5 {
        طباعة("الرقم: {}", رقم)؛
    }
}
```

### مصفوفة وحلقة

```knoz
دالة رئيسية() {
    دع أسماء = ["أحمد", "فاطمة", "علي", "مريم"]؛
    
    طباعة("قائمة الأسماء:")؛
    لكل اسم في أسماء {
        طباعة("  - {}", اسم)؛
    }
}
```

### هيكل بسيط

```knoz
هيكل شخص {
    اسم: نص,
    عمر: صحيح,
}

نفذ شخص {
    دالة جديد(اسم: نص, عمر: صحيح) -> ذاتي {
        ذاتي { اسم, عمر }
    }
    
    دالة عرف(&ذاتي) {
        طباعة("أنا {}, عمري {} سنة", ذاتي.اسم, ذاتي.عمر)؛
    }
}

دالة رئيسية() {
    دع شخص١ = شخص::جديد("أحمد", 25)؛
    شخص١.عرف()؛
}
```

## حل المشاكل الشائعة

### لم يتم التعرف على أمر knoz

```bash
# تأكد من أن كنوز في PATH
echo $PATH | grep knoz

# أعد تشغيل Terminal أو أعد تحميل الملف
source ~/.bashrc  # أو source ~/.zshrc
```

### خطأ في LLVM

كنوز تحتاج LLVM 20. ثبّته:

```bash
# Ubuntu/Debian
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 20

# macOS
brew install llvm@20
```

### الملف بامتداد .كنز لا يُقرأ

تأكد من:
1. استخدام امتداد `.كنز` وليس `.txt`
2. حفظ الملف بترميز UTF-8
3. الملف موجود في مجلد `مصدر/`
