# التحكم في التدفق

تتيح لك عبارات التحكم اتخاذ القرارات وتكرار العمليات في برامجك.

## عبارات الشرط

### إذا البسيطة

```knoz
دع عمر = 25;

إذا عمر >= 18 {
    اطبع("بالغ");
}
```

### إذا مع وإلا

```knoz
دع عمر = 15;

إذا عمر >= 18 {
    اطبع("بالغ");
} وإلا {
    اطبع("قاصر");
}
```

### إذا متعددة (وإلا إذا)

```knoz
دع درجة = 85;

إذا درجة >= 90 {
    اطبع("ممتاز");
} وإلا إذا درجة >= 80 {
    اطبع("جيد جداً");
} وإلا إذا درجة >= 70 {
    اطبع("جيد");
} وإلا إذا درجة >= 60 {
    اطبع("مقبول");
} وإلا {
    اطبع("راسب");
}
```

## الحلقات

### حلقة طالما (while)

تستمر طالما الشرط صحيح:

```knoz
دع متغير ي = 1;

طالما ي <= 5 {
    اطبع("العدد: ");
    اطبع_صحيح(ي);
    ي = ي + 1;
}
```

### حلقة لكل (for)

للتكرار على نطاق من الأعداد:

```knoz
// من 1 إلى 3 (لا يشمل 4)
لكل ن في 1..4 {
    اطبع("تكرار: ");
    اطبع_صحيح(ن);
}
```

:::note[ملاحظة]
النطاق `1..4` يعني من 1 إلى 3 (لا يشمل الرقم الأخير)
:::

### حلقة كرر (loop)

حلقة لا نهائية تتطلب `أوقف` للخروج:

```knoz
دع متغير عداد = 0;

كرر {
    عداد = عداد + 1;
    اطبع("كرر رقم: ");
    اطبع_صحيح(عداد);
    
    إذا عداد >= 3 {
        أوقف;  // الخروج من الحلقة
    }
}
```

## التحكم في الحلقات

### أوقف (break)

للخروج من الحلقة فوراً:

```knoz
لكل ي في 1..10 {
    إذا ي == 5 {
        أوقف;  // يوقف عند 5
    }
    اطبع_صحيح(ي);
}
// يطبع: 1, 2, 3, 4
```

### تابع (continue)

لتخطي التكرار الحالي والانتقال للتالي:

```knoz
لكل م في 1..6 {
    إذا م == 3 {
        تابع;  // يتخطى 3
    }
    اطبع("رقم: ");
    اطبع_صحيح(م);
}
// يطبع: 1, 2, 4, 5
```

## المطابقة (Pattern Matching)

للتحقق من قيم متعددة بطريقة أنيقة:

```knoz
دع رقم = 2;

طابق رقم {
    0 => {
        اطبع("صفر");
    }
    1 => {
        اطبع("واحد");
    }
    2 => {
        اطبع("اثنان");
    }
    _ => {
        اطبع("عدد آخر");
    }
}
```

:::tip[الحالة الافتراضية]
`_` تطابق أي قيمة أخرى لم تُذكر
:::

### المطابقة مع القيم المنطقية

```knoz
دع قيمة = صح;

طابق قيمة {
    صح => {
        اطبع("القيمة صحيحة");
    }
    خطأ => {
        اطبع("القيمة خاطئة");
    }
}
```

## المثال الكامل

```knoz
دالة رئيسية() {
    اطبع("=== عبارات التحكم ===");
    
    // إذا وإلا
    دع عمر = 25;
    إذا عمر >= 18 {
        اطبع("بالغ");
    } وإلا {
        اطبع("قاصر");
    }
    
    // حلقة طالما
    اطبع("=== حلقة طالما ===");
    دع متغير ي = 1;
    طالما ي <= 3 {
        اطبع_صحيح(ي);
        ي = ي + 1;
    }
    
    // حلقة لكل
    اطبع("=== حلقة لكل ===");
    لكل ن في 1..4 {
        اطبع_صحيح(ن);
    }
    
    // المطابقة
    اطبع("=== المطابقة ===");
    دع يوم = 3;
    طابق يوم {
        1 => { اطبع("السبت"); }
        2 => { اطبع("الأحد"); }
        3 => { اطبع("الاثنين"); }
        _ => { اطبع("يوم آخر"); }
    }
}
```
