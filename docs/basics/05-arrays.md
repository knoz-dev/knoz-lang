# المصفوفات والصفوف

كنوز تدعم المصفوفات الثابتة والصفوف لتخزين مجموعات من البيانات.

## المصفوفات (Arrays)

المصفوفات هي مجموعات ثابتة الحجم من عناصر من نفس النوع.

### إنشاء مصفوفة

```knoz
// مصفوفة أعداد صحيحة
دع أعداد = [10, 20, 30, 40, 50];

// مصفوفة أعداد عشرية
دع عشرية = [1.5, 2.7, 3.9, 4.1];
```

### الوصول للعناصر

الفهرسة تبدأ من الصفر:

```knoz
دع أعداد = [10, 20, 30, 40, 50];

دع الأول = أعداد[0];   // 10
دع الثاني = أعداد[1];  // 20
دع الثالث = أعداد[2];  // 30

اطبع_صحيح(الأول);
اطبع_صحيح(الثالث);
```

### حساب مجموع المصفوفة

```knoz
دع قيم = [5, 10, 15, 20, 25];
دع متغير مجموع = 0;

مجموع = مجموع + قيم[0];
مجموع = مجموع + قيم[1];
مجموع = مجموع + قيم[2];
مجموع = مجموع + قيم[3];
مجموع = مجموع + قيم[4];

اطبع("المجموع: ");
اطبع_صحيح(مجموع);  // 75
```

## الصفوف (Tuples)

الصفوف تخزن عناصر من أنواع مختلفة.

### إنشاء صف

```knoz
// صف بنوعين مختلفين
دع صف = (42, 3.14);

// صف متعدد العناصر
دع معلومات = (100, 200, 300);
```

### الوصول لعناصر الصف

استخدم `.رقم` للوصول:

```knoz
دع صف = (42, 3.14);

دع عنصر_أول = صف.0;   // 42
دع عنصر_ثاني = صف.1;  // 3.14

اطبع_صحيح(عنصر_أول);
اطبع_عشري(عنصر_ثاني);
```

### صف متعدد العناصر

```knoz
دع معلومات = (100, 200, 300);

اطبع_صحيح(معلومات.0);  // 100
اطبع_صحيح(معلومات.1);  // 200
اطبع_صحيح(معلومات.2);  // 300
```

## المتجهات (Vectors)

المتجهات هي مصفوفات ديناميكية قابلة للتوسع.

### إنشاء متجه

```knoz
دع م = متجه_جديد(8);  // حجم العنصر 8 بايت
```

### إضافة عناصر

```knoz
دع ق1 = 10;
دع ق2 = 20;
دع ق3 = 30;

متجه_أضف(م, &ق1, 8);
متجه_أضف(م, &ق2, 8);
متجه_أضف(م, &ق3, 8);
```

### عمليات المتجه

```knoz
// الطول
دع الطول = متجه_طول(م);
اطبع_صحيح(الطول);

// المجموع
دع المجموع = متجه_مجموع(م);
اطبع_صحيح(المجموع);

// الحد الأدنى والأقصى
دع الادنى = متجه_الحد_الأدنى(م);
دع الاقصى = متجه_الحد_الأقصى(م);

// المتوسط
دع المتوسط = متجه_متوسط(م);
اطبع_عشري(المتوسط);

// التحقق من وجود قيمة
دع يحتوي = متجه_يحتوي(م, 20);
إذا يحتوي {
    اطبع("المتجه يحتوي على 20");
}

// فهرس القيمة
دع فهرس = متجه_مؤشر(م, 30);
اطبع_صحيح(فهرس);
```

### تحرير الذاكرة

```knoz
متجه_حرر(م);
```

:::caution[هام]
لا تنسَ تحرير المتجه بعد الانتهاء من استخدامه لتجنب تسرب الذاكرة
:::

## المثال الكامل

```knoz
دالة رئيسية() -> صحيح {
    اطبع("=== المصفوفات ===");
    
    // مصفوفة أعداد صحيحة
    دع أعداد = [10, 20, 30, 40, 50];
    اطبع("العنصر الأول:");
    اطبع_صحيح(أعداد[0]);
    
    اطبع("العنصر الثالث:");
    اطبع_صحيح(أعداد[2]);
    
    // مصفوفة عشرية
    اطبع("=== المصفوفة العشرية ===");
    دع عشرية = [1.5, 2.7, 3.9];
    اطبع_عشري(عشرية[1]);
    
    // الصفوف
    اطبع("=== الصفوف ===");
    دع صف = (42, 3.14);
    اطبع("العنصر الأول:");
    اطبع_صحيح(صف.0);
    اطبع("العنصر الثاني:");
    اطبع_عشري(صف.1);
    
    // حساب المجموع
    اطبع("=== حساب المجموع ===");
    دع قيم = [5, 10, 15, 20, 25];
    دع متغير مجموع = 0;
    مجموع = قيم[0] + قيم[1] + قيم[2] + قيم[3] + قيم[4];
    اطبع("المجموع:");
    اطبع_صحيح(مجموع);
    
    أرجع 0;
}
```
