# المتغيرات والأنواع الأساسية

في كنوز، المتغيرات هي أساس تخزين البيانات. تتميز اللغة بنظام أنواع قوي يضمن سلامة الكود.

## تعريف المتغيرات

### المتغيرات الثابتة (غير قابلة للتغيير)

استخدم `دع` لتعريف متغير ثابت:

```knoz
دع عدد = 42;
دع قيمة_عشرية = 3.14159;
دع رسالة = "مرحباً بالعربية!";
دع علم = صح;
```

:::caution[هام]
المتغيرات الثابتة لا يمكن تغيير قيمتها بعد التعريف
:::

### المتغيرات المتغيرة (قابلة للتغيير)

أضف `متغير` لإنشاء متغير قابل للتغيير:

```knoz
دع متغير عداد = 0;
عداد = عداد + 10;  // ✓ مسموح
```

## الأنواع الأساسية

| النوع | الوصف | مثال |
|-------|--------|-------|
| `صحيح` / `ص64` | عدد صحيح 64-بت | `42`, `-100` |
| `عشري` / `ع64` | عدد عشري 64-بت | `3.14`, `-2.5` |
| `نص` | سلسلة نصية | `"مرحباً"` |
| `منطقي` | قيمة منطقية | `صح`, `خطأ` |
| `حرف` | حرف واحد | `'ع'`, `'أ'` |

## أمثلة عملية

### الأعداد الصحيحة

```knoz
دع عمر = 25;
دع درجة_حرارة = -5;
دع عدد_كبير = 1000000;

اطبع_صحيح(عمر);
```

### الأعداد العشرية

```knoz
دع باي = 3.14159;
دع سعر = 99.99;
دع نسبة = 0.75;

اطبع_عشري(باي);
```

### النصوص

```knoz
دع اسم = "أحمد";
دع تحية = "مرحباً بالعالم";

اطبع(اسم);
اطبع(تحية);
```

### القيم المنطقية

```knoz
دع نشط = صح;
دع مكتمل = خطأ;

اطبع_منطقي(نشط);
```

### الحروف

```knoz
دع الحرف_العربي = 'ع';
دع حرف_لاتيني = 'A';
```

## التصريح بالنوع

يمكنك تحديد النوع صراحةً:

```knoz
دع رقم: ص64 = 100;
دع قيمة: ع64 = 3.14;
دع فعال: منطقي = صح;
```

## الثوابت

```knoz
دع باي = 3.14159;  // ثابت - لا يمكن تغييره
```

## نصائح مهمة

:::tip[أفضل الممارسات]
- استخدم أسماء عربية واضحة ومعبرة
- فضّل المتغيرات الثابتة ما لم تحتج للتغيير
- حدد النوع صراحةً عند الحاجة للوضوح
:::

## المثال الكامل

```knoz
دالة رئيسية() {
    // متغيرات ثابتة
    دع عدد = 42;
    دع قيمة_عشرية = 3.14159;
    دع رسالة = "مرحباً بالعربية!";
    دع علم = صح;
    
    // طباعة القيم
    اطبع("عدد صحيح: ");
    اطبع_صحيح(عدد);
    
    اطبع("قيمة عشرية: ");
    اطبع_عشري(قيمة_عشرية);
    
    اطبع("رسالة: ");
    اطبع(رسالة);
    
    // متغير قابل للتغيير
    دع متغير عداد = 0;
    عداد = عداد + 10;
    اطبع("العداد: ");
    اطبع_صحيح(عداد);
}
```
