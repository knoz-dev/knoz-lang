# العمليات الحسابية والمنطقية

كنوز تدعم مجموعة شاملة من العمليات الحسابية والمنطقية وعمليات المقارنة.

## العمليات الحسابية

### العمليات الأساسية

| العملية | الرمز | مثال | النتيجة |
|---------|-------|-------|---------|
| الجمع | `+` | `20 + 7` | `27` |
| الطرح | `-` | `20 - 7` | `13` |
| الضرب | `*` | `20 * 7` | `140` |
| القسمة | `/` | `20 / 7` | `2` |
| باقي القسمة | `%` | `20 % 7` | `6` |

```knoz
دع أ = 20;
دع ب = 7;

اطبع_صحيح(أ + ب);  // 27
اطبع_صحيح(أ - ب);  // 13
اطبع_صحيح(أ * ب);  // 140
اطبع_صحيح(أ / ب);  // 2
اطبع_صحيح(أ % ب);  // 6
```

### العمليات على الأعداد العشرية

```knoz
دع س = 10.5;
دع ص = 3.2;

اطبع_عشري(س + ص);  // 13.7
اطبع_عشري(س - ص);  // 7.3
اطبع_عشري(س * ص);  // 33.6
اطبع_عشري(س / ص);  // 3.28125
```

## العمليات المنطقية

| العملية | الرمز | الوصف |
|---------|-------|--------|
| و | `و` أو `&&` | صحيح إذا كلا الطرفين صحيح |
| أو | `أو` أو `\|\|` | صحيح إذا أحد الطرفين صحيح |
| نفي | `!` | يعكس القيمة المنطقية |

```knoz
دع ع1 = صح;
دع ع2 = خطأ;

// و المنطقية
اطبع_منطقي(ع1 و ع2);   // خطأ

// أو المنطقية
اطبع_منطقي(ع1 أو ع2);  // صح

// النفي
اطبع_منطقي(!ع1);       // خطأ
اطبع_منطقي(!ع2);       // صح
```

## عمليات المقارنة

| العملية | الرمز | الوصف |
|---------|-------|--------|
| يساوي | `==` | التحقق من المساواة |
| لا يساوي | `!=` | التحقق من عدم المساواة |
| أكبر من | `>` | أكبر من |
| أصغر من | `<` | أصغر من |
| أكبر أو يساوي | `>=` | أكبر من أو يساوي |
| أصغر أو يساوي | `<=` | أصغر من أو يساوي |

```knoz
دع أ = 20;
دع ب = 7;

اطبع_منطقي(أ > ب);   // صح
اطبع_منطقي(أ < ب);   // خطأ
اطبع_منطقي(أ == ب);  // خطأ
اطبع_منطقي(أ != ب);  // صح
اطبع_منطقي(أ >= 20); // صح
اطبع_منطقي(ب <= 7);  // صح
```

## أولوية العمليات

ترتيب الأولوية من الأعلى للأقل:

1. `!` (النفي)
2. `*`, `/`, `%` (الضرب والقسمة)
3. `+`, `-` (الجمع والطرح)
4. `<`, `>`, `<=`, `>=` (المقارنة)
5. `==`, `!=` (المساواة)
6. `و` (و المنطقية)
7. `أو` (أو المنطقية)

استخدم الأقواس لتوضيح الأولوية:

```knoz
دع ناتج = (أ + ب) * 2;  // الجمع أولاً، ثم الضرب
```

## المثال الكامل

```knoz
دالة رئيسية() {
    اطبع("=== العمليات الحسابية ===");
    
    دع أ = 20;
    دع ب = 7;
    
    اطبع("الجمع 20+7: ");
    اطبع_صحيح(أ + ب);
    
    اطبع("الطرح 20-7: ");
    اطبع_صحيح(أ - ب);
    
    اطبع("الضرب 20*7: ");
    اطبع_صحيح(أ * ب);
    
    اطبع("=== العمليات المنطقية ===");
    دع ع1 = صح;
    دع ع2 = خطأ;
    
    اطبع("صح و خطأ: ");
    اطبع_منطقي(ع1 و ع2);
    
    اطبع("صح أو خطأ: ");
    اطبع_منطقي(ع1 أو ع2);
    
    اطبع("=== المقارنات ===");
    اطبع("أ > ب: ");
    اطبع_منطقي(أ > ب);
}
```
